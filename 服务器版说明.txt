CIRCUITORIUM 工具箱 · 关于「服务器版」
========================================

一、先说结论
------------
这个项目是个人开发的，**没有收入去支撑服务器成本**，所以我把重心放在了两个
**本地版**上——它们不依赖任何服务器，双击就能用，功能一点不少：

  · 桌面版   D:\circuitorium-toolbox\桌面版\CIRCUITORIUM工具箱.exe
  · 便携版   D:\circuitorium-toolbox\便携版\启动.bat（解压即用，可拷给别人）

如果你就喜欢服务器版这个页面（要登录、有项目列表和社区广场的那套界面），
**也完全可以继续用这个版本**——它和上面两个版本**没有差别**：

  · 元件库（20 个内置元件 + 自己添加 + 跟着作品传播）
  · 始解 / 卍解 两种难度，卍解作品带「程序代码 / 接线表 / 调试记录 / 开发环境」
  · 作品文件（.ecp）的分享与接收、AI 识别（可选）
  这些内容都在这套代码里，服务器版一样能用到（顶栏「工具箱」就是入口）。

二、目前暂停的方向
------------------
**「云端共享」这个方向暂时停止推进**——也就是把作品公开到互联网、让别人通过
公网链接访问、社区广场互通这一类需要长期在线服务器的功能。

原因很直接：服务器要一直开着、要花钱、要维护，个人项目扛不住。
所以：

  · 已经做好的登录 / 社区 / 公开分享链接这些页面**保留不动**，想用还能用
  · 但不会再往这个方向加新功能，也不会为了它去购买或续费服务器
  · 需要把作品给别人时，请用**本地版的传播方式**：分享页 HTML、作品码、
    作品文件 .ecp，或者直接把便携版/桌面版发给对方——这些都不需要服务器

三、三种用法怎么选
------------------
  只想自己/教室电脑上用      → 桌面版（双击 exe）
  想拷给别人、U 盘发出去      → 便携版（解压双击 启动.bat）
  想让全班手机连同一个 WiFi 打开 → 便携版里的「启动（全班可访问）.bat」
  想要登录、项目列表、社区那套界面 → 服务器版（本目录，npm run dev）

四、服务器版怎么跑
------------------
  双击本目录的「启动.bat」，或：
      npm run dev           开发模式（改代码即时生效）
      npm run build && npm start   生产模式

  默认地址 http://localhost:3000 ；启动脚本会把「同一个 WiFi 下手机能用的地址」
  一起打印出来。数据库是本目录下的 data.db，上传的图片在 public/uploads/，
  这两样都不会被提交到仓库，换机器时记得一起拷走。

五、我不太想让人误会的地方
--------------------------
  · 服务器版**不是**"更高级的版本"，它只是同一套界面的另一种跑法
  · 本地版**不是**"功能缩水版"，元件库、始解/卍解、作品传播它全都有
  · 「暂停云端共享」不等于"删掉了社区"——页面都还在，只是不再往那个方向投入

最后一句：这个项目更适合被"拿走"而不是被"访问"。把便携版拷给同学，
比给他们一个链接更靠谱——断网也能用，几年后打开还在。
