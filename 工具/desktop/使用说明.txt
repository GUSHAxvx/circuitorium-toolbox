CIRCUITORIUM 工具箱 · 桌面版
==============================

双击「CIRCUITORIUM工具箱.exe」就能用。
不用装 Node、不用装浏览器插件、不用联网、不用管理员权限。
（界面和便携版一模一样，只是外面套了一个 Windows 窗口，不再需要那个最小化的服务窗口。）

第一次打开会看到什么
--------------------
自带 3 件示例作品和 5 套模板，可以直接改、直接删。
带「示例作品」标记的是给你照着做的；「收到的作品」是别人发给你的，点「做同款」复制一份再改，
原件不会被改乱。

元件库
------
工具栏上的「元件库」里有 20 个内置元件（电阻、电容、二极管、三极管、传感器、Arduino 板…），
每个都有图、有「怎么认 / 正负极 / 怎么读参数 / 新手常踩的坑」。

但内置的只是起步用的，更鼓励自己加：
- 「＋ 自己加一个」：拍张图、写上说明，它就和新内置的一样好用
- 你自建的元件会**跟着作品一起发给别人**：同学收下你的作品，就能把元件收进他自己的库
- 有能力的同学可以在「识别设置」里接自己的识别服务，拍张照自动生成元件卡，攒库快得多

作品还有「难度」之分
--------------------
新建作品时可以选：
- **始解**：搭起来就行，不用写代码（默认）
- **卍解**：要写代码，作品页会多出四个标签页——程序代码（支持 Keil 的 .uvproj/.c/.h/.s，
  中文注释是 GBK 也不会乱码）、接线表、调试记录、开发环境
这些内容都会跟着作品文件一起传给下一个人。

数据存在哪
----------
存在这台电脑上：C:\Users\<你的用户名>\AppData\Local\com.circuitorium.toolbox
- 卸载/删掉 exe 不会丢数据；要清空就在系统里删掉上面这个文件夹
- 换电脑：作品用「分享作品」→「作品文件」存成 .ecp 带走，新电脑上「打开作品」即可

怎么把作品给别人
----------------
打开作品 → 右上角「分享作品」，三种方式随便挑：
- 分享页：生成一个 HTML 文件，对方双击就能看，页面里点一下就能存进自己的工具箱
- 作品码：小体量作品压成一串码（可投屏成二维码让学生扫）
- 作品文件：一个 .ecp 文件，图片原样保留，适合大作品或存档

想让全班用手机打开？
--------------------
桌面版是自己看的窗口，**不能**让手机访问。
要"全班手机连同一个 WiFi 就能打开"，用便携版：双击 `便携版\启动（全班可访问）.bat`，
它会把手机能用的网址打印出来（详见便携版里的《使用说明.txt》）。

保存文件时
----------
桌面版会弹出 Windows 原生的「另存为」对话框，自己选存哪儿（浏览器版是直接下到「下载」文件夹）。

AI 识别（可选）
---------------
「识别设置」里有三种模式：手动录入（默认，零配置）、本机识别凭据、老师配置码。
不配置也完全能用工具箱的全部功能，包括手动添加元件和整个元件库。

快捷键
------
F5 / Ctrl+R：刷新界面（不丢数据）
Esc：关闭弹层
