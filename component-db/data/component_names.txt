补一个元件的流程（每个约 5 分钟）：
1. 在 D:\fritzing-parts 的 filelist.txt 里找 `core/xxx.fzp`
2. 加进 scripts/parts.json
3. `python scripts/extract_fritzing.py` → `node scripts/render_images.mjs`
4. 在 data/components_text.json 里补一条教学文案
5. `python scripts/merge_validate.py --strict` → `npm run sync:library`
